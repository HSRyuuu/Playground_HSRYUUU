# 선착순 쿠폰 발급 — 요구사항

## 1. 도메인 개요

**선착순 1,000명에게 쿠폰을 발급하는 단일 인스턴스 Spring Boot 애플리케이션.**
대용량 트래픽이 짧은 시간에 몰리는 시나리오를 다양한 동시성 제어 방식으로 점진적으로 개선해 나간다.

## 2. 핵심 비즈니스 규칙

| # | 규칙 | 설명 |
|---|---|---|
| R1 | 총 발급 수량 | 한 쿠폰당 최대 1,000개 발급 |
| R2 | 1인 1회 | 동일 유저가 같은 쿠폰을 두 번 발급받을 수 없음 |
| R3 | 결과 | 발급 결과는 **성공 / 실패** 둘 중 하나 (재시도/대기열 없음) |
| R4 | 재고 정확성 | `issued_quantity` ≤ `total_quantity` 가 어떤 부하 상황에서도 보장되어야 함 |
| R5 | 응답 일관성 | 발급 성공 응답을 받은 유저는 항상 `coupon_issue` 레코드가 존재해야 함 |

## 3. API 스펙

| Method | Path | 설명 |
|---|---|---|
| `POST` | `/api/v1/coupons/{couponId}/issue` | 쿠폰 발급 요청 (body: `{ userId }`) |
| `GET`  | `/api/v1/coupons/{couponId}` | 쿠폰 상태(총 수량 / 발급 수량) 조회 |
| `GET`  | `/api/v1/coupons/{couponId}/issues/count` | 발급 카운트 조회 |

### 에러 응답

| HTTP | 상황 |
|---|---|
| 404 | 존재하지 않는 쿠폰 |
| 409 | 이미 발급받은 유저 (R2 위반) |
| 409 | 수량 소진 (R1 위반) |
| 400 | 입력값 오류 (`userId` 양수 아님 등) |

## 4. 도메인 모델

```
Coupon
 ├─ id
 ├─ name
 ├─ totalQuantity     // R1
 └─ issuedQuantity    // 누적 발급 수량

CouponIssue
 ├─ id
 ├─ couponId
 ├─ userId
 ├─ issuedAt
 └─ UNIQUE (couponId, userId)   // R2 (DB 레벨 안전망)
```

## 5. 비기능 요구사항

- **단일 인스턴스 가정** — 멀티 인스턴스는 후속 단계에서 다룸
- **외부 의존성 최소화** — 1~2단계는 DB만, 3단계부터 Redis / Kafka 도입
- **재현 가능한 부하 테스트** — 각 단계마다 동일한 시나리오로 회귀 비교

## 6. 학습 로드맵 (단계별)

각 단계는 **이전 단계의 한계를 부하 테스트로 드러낸 뒤** 다음 단계로 진행한다.

| 단계 | 구현 방식 | 드러나는 문제 |
|---|---|---|
| **1** | 가장 단순한 JPA 구현 (read-then-write) | Race condition으로 R1, R2 위반 |
| 2 | 애플리케이션 레벨 `synchronized` / `ReentrantLock` | 단일 인스턴스에서는 안전, 다중 인스턴스에서 깨짐 |
| 3 | DB Pessimistic Lock (`SELECT ... FOR UPDATE`) | 정확하지만 처리량 저하 (락 경합) |
| 4 | DB Optimistic Lock (`@Version`) | 충돌 시 재시도 비용, 실패율 증가 |
| 5 | Redis 원자 연산 (`INCR` / Lua) | 단일 인스턴스 한계 돌파, but 영속성/정합성 이슈 |
| 6 | Redis + Kafka 비동기 발급 | 응답 빠르지만 결과 정합성을 어떻게 보장할 것인가 |
| 7 | 대기열 / 백프레셔 | 트래픽 자체를 제어 |

> 본 문서는 전체 로드맵을 제시하며, **현재 진행 중인 단계의 상세는 `README.md`에 기술**한다.

## 7. 단계 진행 규칙

1. **구현 → 부하 테스트 → 문제 식별 → 다음 단계 설계**의 순서를 지킨다.
2. 새 단계는 새로운 `CouponIssueServiceVN` 구현체로 추가하고, 이전 구현은 비교용으로 보존한다.
3. 각 단계는 README.md의 "현재 단계" 섹션을 갱신해 학습 흐름을 추적한다.
