# 쿠폰 발급 (Coupon)

## 개요
선착순으로 정해진 수량의 쿠폰을 정확히 발급하고, 1인 1매를 보장한다.

## 핵심 요구사항
- 쿠폰 이벤트를 생성한다 (총 수량, 기간 설정)
- 사용자가 쿠폰 발급을 요청하면 선착순으로 발급한다
- 정확히 N장만 발급되어야 한다 (초과 발급 불가)
- 동일 사용자는 같은 이벤트에서 1매만 발급받을 수 있다
- 쿠폰 이벤트 현황 및 사용자별 보유 쿠폰을 조회할 수 있다

## 핵심 기술
- Redis Set (SADD로 중복 방지)
- Redis DECR 또는 Lua Script (수량 제어)
- Kafka Consumer (비동기 발급)

## 비교 전략
- v1: 동기 발급 (Redis + DB 직접)
- v2: 비동기 발급 (Kafka Consumer)
