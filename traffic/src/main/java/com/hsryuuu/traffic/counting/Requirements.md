# 좋아요/투표 (Counting)

## 개요
초당 수만 건의 쓰기 요청을 처리하면서 실시간 집계를 제공한다.

## 핵심 요구사항
- 게시글에 좋아요를 누르거나 취소할 수 있다
- 동일 사용자의 중복 좋아요를 방지한다
- 게시글의 좋아요 수를 실시간으로 조회할 수 있다

## 핵심 기술
- Redis INCR/DECR (실시간 카운터)
- Redis Set (중복 방지)
- Write-back 배치 (주기적 DB 동기화)

## 비교 전략
- v1: DB 직접 UPDATE (매 요청마다)
- v2: Redis 카운터 + 배치 Write-back
